# Protokolle

Hier liegen die Ergebnisprotokolle der Treffen der Gesamtgruppe von Project JLU, eine Datei je Sitzung.

- **Treffen der Gesamtgruppe** mit der Betreuung: Das Protokoll legt die Betreuung ab.
- **Treffen eines Teams** ohne die Betreuung: Das Team protokolliert selbst und legt das Protokoll in seiner eigenen Ablage ab.

Dateiname: Datum und Anlass, etwa `2026-11-27_gesamtgruppe.md`.

Ein Ergebnisprotokoll hält fest, was entschieden wurde, wer was bis wann erledigt und welche Fragen offen sind.
